# 💼 Naukri.com Clone Project (HTML & CSS)

## 📌 Project Overview
This project is a simple frontend clone of Naukri.com built using HTML and CSS.  
It includes multiple pages like landing page, login, signup, dashboard, etc.

---

## 🎯 Features
- Landing Page UI
- Login & Signup Page
- Forgot Password Page
- User Dashboard
- Admin Dashboard
- Job Detail Page
